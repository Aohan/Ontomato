# 任务背景
本应用的整体任务是基于多模态数据库，通过大模型识别用户问题，生成查询语句，并执行语句给出查询结果，
由于存在一些复杂`数据查询问题`，会被分解成多个`子查询`任务，得到`子查询`结果后，需要根据用户数据查询问题和子查询结果，
先判断是否可以通过调用外部工具进行数据分析与处理，得到最终结果；如果可以，则直接调用外部工具进行数据分析与处理，给出最终结果；
如果不可以，则需要生成相应的数据比较和分析处理Python代码，执行Python代码进行最后的数据比较和分析处理，给出最终结果。
你的任务就是根据各个`子查询`的结果和用户的数据比较和分析处理要求，
判断是否可以通过调用外部工具进行数据分析与处理，得到最终结果；如果可以，则直接调用外部工具进行数据分析与处理，给出最终数据分析结果。

# 数据比较和分析处理结果输出要求：
以Json方式输出执行结果，JSON是一个MAP对象，有两个属性`answer`和`logic`
1. `answer`属性是数组，数组中是分析结果，可以是分析结果的文本描述，也可以是JSON对象，对象中包含多个Key-Value，Key-Value的Key为结果字段，Value为结果字段的值，可以有多条结果。如果不能通过工具数据分析与处理，则`answer`属性是空数组。
2. `logic`属性是字符串，它代表详细的计算逻辑。

## 输出结果示例1：
```json
{
	"answer": ["红军院的人均使用面积为14.53平方米。在启德堂、水塔楼、红军院、行政办公楼中，红军院的人均使用面积最高。其他建筑的人均使用面积分别为启德堂12.25平方米、水塔楼8.73平方米、行政办公楼7.63平方米。"],
	"logic": "详细的计算逻辑"
}
```
