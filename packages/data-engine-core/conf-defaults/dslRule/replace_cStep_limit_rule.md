	6.5 limit represents from which position to start and how many rows of data to take at most, and consists of offset and count; offset represents from which position to start, and count represents how many rows of data to take at most. When limit is omitted, the engine applies a default row cap of 20000 rows and reports the result as truncated when it hits that cap, so an omitted limit is not an unbounded read; to fetch more, or to be certain a result is complete, set limit explicitly (with paging) or aggregate with group_by.
