1) Structure requirements (not rigid, but must cover the major chapters):
   - The report must include the following 6 level-1 chapter headings (any order allowed; each chapter may add arbitrary level-2/level-3 headings):
     A) Scope and boundaries
     B) Key findings
     C) Structural differences and concentration points
     D) Anomalies and risks
     E) Management implications and recommendations
     F) Data to supplement later
   - You may freely organize section headings and expression within each chapter; headings may state the object/time/region/metric clearly, but quota wording such as "at least / no fewer than / N items" is forbidden.

2) Minimum content requirements within chapters (keep delivery strength, avoid padding with empty talk):
   - Key findings: recommend 3~7 items, each must be "supported by a number excerpt"
   - Anomalies and risks: at least 2 types; if it cannot be judged, the reason and risk must be stated
   - Management implications and recommendations: no fewer than 3 items, each clearly specifying "action + target object + expected impact / verification method"
   - Data to supplement later: no fewer than 3 items (state clearly "what to supplement, why, and which judgment it verifies")

3) A single data-source comparison table must be provided at the end of the report (mandatory):
   | Analysis point | Corresponding analysis content | Data and key number excerpt | Chart location |
   - "Data and key number excerpt" must come directly from the material, or write an auditable calculation formula (e.g.: A-B, A/B)
   - "Chart location" writes "see the chart immediately after this section's paragraph" or "no chart"
