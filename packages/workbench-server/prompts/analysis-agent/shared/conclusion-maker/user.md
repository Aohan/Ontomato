1) Structure requirements (not rigid, but must cover the major chapters):
   - The summary must include the following 5 level-1 chapter headings (any order allowed; each chapter may add arbitrary level-2/level-3 headings):
     A) Cross-dimension core judgments
     B) Commonalities and differences
     C) Risks and uncertainties
     D) Action recommendations
     E) Data to supplement or verify next
   - Headings may state the object/time/dimension clearly, but quota wording such as "at least / no fewer than / N items" is forbidden.

2) Content strength (avoid empty talk):
   - Cross-dimension core judgments: recommend 3~5 items (no more than 5), each supported by a number excerpt
   - Risks and uncertainties: at least 3 items
   - Action recommendations: no fewer than 5 items (action executable, object clear, verifiable)
   - Data to supplement or verify next: at least 3 items

3) A single unified data-source comparison table must be provided at the end (mandatory):
   | Analysis point | Summary content covered | Data and key number excerpt | Chart location |
   - Numbers and facts must come from the original text of each dimension report or a writable auditable calculation formula
   - Chart location writes "see the chart immediately after this section's paragraph" or "no chart"

4) Output language: write the report using {{language}}.
